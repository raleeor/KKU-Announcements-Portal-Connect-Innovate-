## نظرة عامة

بوابة إعلانات جامعة الملك خالد هي تطبيق ويب يوفر للطلاب والمسؤولين منصة مركزية لعرض وإدارة إعلانات الكليات والدورات والأندية والفعاليات الجامعية — بواجهة عربية كاملة مع دعم للوضعين الفاتح والداكن.

## المميزات

| الميزة | الوصف |
|--------|-------|
| تسجيل الدخول | رقم جامعي + كلمة مرور مع تمييز دور المستخدم والمسؤول |
| الصفحة الرئيسية | بحث وتصفية حسب الكلية، مع أقسام للدورات والأندية والإعلانات العامة |
| إدارة الإعلانات | المسؤولون يستطيعون إضافة إعلانات جديدة من خلال نموذج مخصص |
| الإشعارات | قائمة إشعارات منبثقة عبر زر الجرس في الشريط العلوي |
| سجل الدورات | صفحة تعرض الدورات المكتملة للمستخدم |
| صفحة الاقتراحات | إرسال ملاحظات ومقترحات لإدارة الجامعة |
| الإعدادات | تبديل الوضع الليلي/النهاري وتغيير اللغة (عربي/إنجليزي) |
| التصميم المتجاوب | يعمل على الهاتف والجهاز اللوحي وسطح المكتب |

## تشغيل المشروع محلياً

### المتطلبات
- [Node.js](https://nodejs.org) الإصدار 18 أو أحدث
- [pnpm](https://pnpm.io) الإصدار 8 أو أحدث

### الخطوات

```bash
# 1. استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/kku-announcements.git
cd kku-announcements

# 2. تثبيت الحزم
pnpm install

# 3. تشغيل بيئة التطوير
pnpm dev

# 4. فتح المتصفح على
# http://localhost:5173
```

### بناء النسخة الإنتاجية

```bash
pnpm build
```

تجد الملفات الناتجة في مجلد `dist/`.

## هيكل المشروع

```

├── app/
│   ├── App.tsx                        # المكون الجذر وإدارة الحالة العامة
│   └── components/
│       ├── LoginPage.tsx              # صفحة تسجيل الدخول
│       ├── MainLayout.tsx             # التخطيط الرئيسي بعد الدخول
│       ├── Header.tsx                 # الشريط العلوي
│       ├── HomePage.tsx               # الصفحة الرئيسية
│       ├── SearchBar.tsx              # شريط البحث
│       ├── FilterBar.tsx              # شريط التصفية
│       ├── CollegeAnnouncementsSection.tsx
│       ├── CoursesSection.tsx         # قسم الدورات
│       ├── ClubsSection.tsx           # قسم الأندية
│       ├── GeneralAnnouncementsSection.tsx

│       ├── AnnouncementsList.tsx      # قائمة الإعلانات

│       ├── NotificationsDropdown.tsx  # قائمة الإشعارات
│       ├── SettingsPage.tsx           # صفحة الإعدادات
│       ├── CoursesHistoryPage.tsx     # سجل الدورات
│       ├── SuggestionsPage.tsx        # صفحة الاقتراحات
│       └── ui/                        # مكونات Radix UI المخصصة
└── styles/
    ├── index.css                      # نقطة دخول الأنماط
    ├── theme.css                      # متغيرات الألوان والتصميم
    └── fonts.css                      # استيراد الخطوط
```
