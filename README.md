# KKU-Announcements-Portal-Connect-Innovate-
KKU digital announcements portal built for Connect &amp; Innovate Hackathon — React + TypeScript
بوابة إعلانات جامعة الملك خالد
KKU Announcements Portal

منصة رقمية موحدة لإعلانات الكليات والأندية والفعاليات الجامعية

React Vite TypeScript Tailwind CSS

    🏆 هذا المشروع تم بناؤه خلال هاكثون Connect & Innovate

نظرة عامة

بوابة إعلانات جامعة الملك خالد هي تطبيق ويب يوفر للطلاب والمسؤولين منصة مركزية لعرض وإدارة إعلانات الكليات والدورات والأندية والفعاليات الجامعية — بواجهة عربية كاملة مع دعم للوضعين الفاتح والداكن.

الخطوات

# 1. استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/kku-announcements.git
cd kku-announcements

# 2. تثبيت الحزم
pnpm install

# 3. تشغيل بيئة التطوير
pnpm dev

# 4. فتح المتصفح على
# http://localhost:5173

بناء النسخة الإنتاجية

pnpm build

تجد الملفات الناتجة في مجلد dist/.
